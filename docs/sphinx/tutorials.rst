Tutorials
=========

These tutorials are runnable Jupyter notebooks from the ``notebooks/``
directory of the repository, rendered here with their saved outputs. Each one
is self-contained; download it and run it to experiment. An editable install is
all they need (see :doc:`installation`). They are generated by
``scripts/build_tutorials.py``; edit that script rather than the notebook JSON.

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Notebook
     - What it covers
   * - :doc:`notebooks/01_getting_started`
     - SNR for a given time, time for a target SNR, the count-rate budget and
       the ``sim.plot()`` overview.
   * - :doc:`notebooks/02_components_and_parameters`
     - The four components, the photometric aperture choice, the ESC filter
       set with EOL/BOL curves, ``from_components``, ``update()`` and
       ``reset()``.
   * - :doc:`notebooks/03_coronagraph_and_contrast`
     - What contrast, post-processing gain and separation do to the SNR curve,
       drawn with ``plot_snr_vs_time(sweep=...)``, plus reference subtraction.
   * - :doc:`notebooks/04_integration_time_snr_saturation`
     - Frame time and read noise, inverting for integration time, and the
       saturation check with its caveat.

.. note::

   ``ESC_ExposureTimeSNRCalculator_Demo.ipynb`` and ``etc_esc_requirements.py``
   in ``notebooks/`` use the pre-refactor API and do not run; they are kept for
   reference only.
